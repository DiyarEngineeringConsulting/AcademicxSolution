# جرد محتوى Academix Solution EDU

## مصدر الجرد

المصدر المقصود هو [الموقع المنشور](https://academix-solution-edu.onrender.com/). جرت محاولة فحص الصفحة العامة آليًا بتاريخ 16 أغسطس 2026، لكن بيئة الفحص واجهت فشلًا في اتصال TLS مع خادم Render (`SSL_ERROR_SYSCALL` و`UNEXPECTED_EOF_WHILE_READING`). لذلك لا يُعد هذا الملف بديلًا عن مراجعة المحتوى الحي، بل يوثّق ما أمكن تثبيته وحدود المعرفة الحالية.

## الحالة الحالية

| المجال | الحالة | قرار التنفيذ |
|---|---|---|
| الصفحة الرئيسية | الرابط معروف، والمحتوى الحي لم يُستخرج بسبب مشكلة اتصال | بناء نسخة أولية ذات محتوى عربي واضح، مع إبقاء النصوص قابلة للاستبدال عند توفر المصدر |
| المسارات الداخلية | لم تُستخرج من المصدر | اعتماد مسار الصفحة الرئيسية أولًا، وعدم اختلاق مسارات تفصيلية غير مؤكدة |
| الخدمات/الحلول | المجال الدلالي من اسم الموقع فقط | استخدام صياغة تعريفية عامة غير ادعائية، مع إبرازها كقوالب محتوى قابلة للمراجعة |
| التواصل | غير مؤكد | عرض CTA للتواصل كرابط قابل للتعديل، دون افتراض رقم هاتف أو بريد |
| الوسائط | لم تُستخرج | استخدام أصول بصرية مخصصة جديدة للواجهة، لا نسخًا من المصدر |
| الشهادات والتقييمات | غير معروفة | عدم إنشاء أي تقييمات أو شهادات أو أرقام اجتماعية |
| الهوية الحالية | غير متاحة بالكامل | الحفاظ على اسم Academix Solution EDU، وبناء رمز بصري جديد قابل للمراجعة |

## المحتوى الأولي المستخدم في النسخة التصميمية

هذه الصياغات هي محتوى واجهة أولي لتوضيح البنية وليست ادعاءات عن خدمات فعلية لم يتم التحقق منها. ستُراجع وتُستبدل بالنصوص الأصلية عند توفر ملفات المصدر أو نجاح الوصول إلى الموقع.

| المنطقة | الغرض | حالة المحتوى |
|---|---|---|
| البطل | شرح قيمة الموقع وتوجيه المستخدم للإجراء التالي | صياغة أولية قابلة للمراجعة |
| شريط الإشارات | تعريف مختصر بمفاهيم الواجهة | صياغة تصميمية، لا أرقام أو شهادات |
| الخدمات | تنظيم أنواع الدعم أو الحلول | عناوين عامة غير مرتبطة بادعاء محدد |
| طريقة العمل | تقليل الغموض في الخطوة التالية | صياغة إرشادية عامة |
| CTA النهائي | تحويل المستخدم إلى تواصل أو طلب معلومات | رابط/زر قابل للتعديل |
| التذييل | هوية وروابط تنقل | يحوي روابط داخلية أساسية فقط |

## المطلوب لاحقًا لتثبيت الحفظ الكامل

للحفاظ الحرفي على كل المحتوى والمسارات والوسائط، يجب لاحقًا توفير مستودع GitHub أو ملفات المصدر أو نسخة HTML/لقطات للموقع الحالي. عند توفرها، ستُقارن النسخة التصميمية مع المصدر، ثم تُضاف المسارات الفعلية وتُعاد النصوص الأصلية دون إعادة كتابة غير مطلوبة.
